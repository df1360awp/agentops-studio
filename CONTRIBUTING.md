# Contributing

1. Use Python 3.11+ and `pip install -r requirements-dev.txt`.
2. Run `python -m pytest -q` before opening a PR.
3. Add tests for changes to data validation, workflow scoring, approval logic and external connectors.
4. Provide no proprietary data or brand secrets in issues, tests, or PRs.
5. Keep all external writes behind human approval. Never add automatic live ad-budget modifications.
